# AgriPulse

AgriPulse is an AI-powered agricultural intelligence platform dedicated to transforming agriculture through data, technology, and innovation. We empower farmers, agribusinesses, financial institutions, researchers, and policymakers with actionable insights that improve productivity, sustainability, and resilience across the agricultural value chain.

## About AgriPulse

Agriculture is facing unprecedented challenges. Climate change, population growth, food insecurity, limited access to financing, and fragmented agricultural systems continue to threaten global food production.

AgriPulse was created to address these challenges by democratizing agricultural intelligence. By combining real-time data, artificial intelligence, machine learning, and agricultural expertise, we help stakeholders make informed decisions that drive sustainable agricultural development. :contentReference[oaicite:0]{index=0}

## Installation

### Clone Repository

```bash
git clone https://github.com/leemwenda/agripulse-node.git
cd agripulse-node
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root:

```env
PORT=5000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=agripulse

JWT_SECRET=your_secret_key
```

### Run Development Server

```bash
npm run dev
```

### Run Production Server

```bash
npm start
```
